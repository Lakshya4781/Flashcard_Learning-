# Cram – The Flashcard Learning Tool

**Cram** is a lightweight and responsive flashcard-based learning tool designed to enhance active recall and self-paced learning. Built using modern web technologies, it provides users with a clean interface to create, review, and manage flashcards efficiently.

## Features

- Create and manage custom flashcards
- Flip functionality for active recall
- Responsive UI optimized for desktop and mobile
- Minimal and clean design using Tailwind CSS

## Tech Stack

- React.js (Front-end framework)
- Tailwind CSS (Utility-first CSS framework)
- JavaScript (Application logic)
- Node.js & npm (Project setup and dependencies)

## Getting Started

To run the project locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/Lakshya4781/Flashcard_Learning-.git
   cd Flashcard_Learning-
2. Install dependencies
   npm install
3. Start the development server
   npm start
   Open http://localhost:3000 in your browser to view the app.
